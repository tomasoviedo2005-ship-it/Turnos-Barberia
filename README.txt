TOMÁS OVIEDO - TURNOS

ARCHIVOS
- index.html: página principal
- manifest.json: configuración de instalación como app (PWA)
- sw.js: service worker y caché
- icon-192.png / icon-512.png / icon-1024.png: iconos de la app

PUBLICAR EN GITHUB PAGES
1. Abrí tu repositorio de GitHub.
2. Subí TODOS estos archivos a la raíz del repositorio.
3. Verificá que exista index.html en la raíz.
4. En Settings > Pages, seleccioná Deploy from a branch, rama main y carpeta /(root).
5. Guardá y esperá la publicación.

IMPORTANTE
Los turnos se guardan actualmente en localStorage, por lo que cada dispositivo/navegador tiene sus propios turnos. Para que clientes y administrador compartan los mismos turnos hace falta una base de datos/backend.

INSTALAR
Android: Chrome > menú > Instalar aplicación / Agregar a pantalla principal.
iPhone: Safari > Compartir > Agregar a pantalla de inicio.
